# 音源の差し替え手順

このフォルダに以下のファイル名で mp3 を置くだけで有効になります。
**置かなかったファイルは単に鳴りません**（エラーにはならず、無音のまま動作します）。

| ファイル名 | 用途 | 鳴るタイミング |
|---|---|---|
| `bgm1.mp3` | 通常BGM | 両者とも4000以上 |
| `bgm2.mp3` | ピンチBGM | どちらかが3999以下 |
| `bgm3.mp3` | 危機BGM | どちらかが1999以下 |
| `bgm4.mp3` | 特殊BGM | **お互い3999以下（最優先）** |
| `damage.mp3` | 減少音 | ライフが減った時（`−` と `÷2`） |
| `coin.mp3` | コイントス | アクセサリのコイン |
| `dice.mp3` | サイコロ | アクセサリのダイス |

## 注意

- **BGMはループ再生されます。** ループしても違和感のない素材を選んでください。切替時に300msのクロスフェードがかかります。
- ファイル形式は mp3 を推奨（iOS Safari / Android Chrome の両方で確実に鳴ります）。
  他の形式にしたい場合は `index.html` 冒頭の `var AUDIO = {...}` のパスを書き換えてください。
- **遊戯王の公式音源（アニメ・ゲームのBGM）は著作権上使用できません。** フリー素材（例：DOVA-SYNDROME、効果音ラボ など、各サイトの利用規約を確認のうえ）または自作音源を使ってください。
- ブラウザの仕様上、**ページを開いた直後は音が鳴りません。** 画面のどこかを最初にタップした時点で音声が有効になります（それまでヘッダーに「🔇 タップで音声ON」と表示されます）。
- 音量はアプリの設定画面（⚙）で BGM / 効果音 それぞれ調整できます。

## 差し替え後

Service Worker が古いファイルをキャッシュしている場合があります。音源を入れ替えても反映されない時は、
`sw.js` の1行目付近にある `var CACHE = 'ygolife-v1';` の数字を上げて再デプロイしてください。
